# Smart Meal Planner

> Tell us your budget. We'll plan your meals.

A budget-first, pack-aware meal planning application built with React, Vite, TypeScript, CSS Modules, Three.js, Express, Firebase Auth/Firestore, and server-side Gemini recipe generation.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the unit test & contrast suite:
   ```bash
   npm test
   npm run contrast
   npm run rules:lint
   ```
3. Start development (Express API + Vite middleware on port 3000):
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
