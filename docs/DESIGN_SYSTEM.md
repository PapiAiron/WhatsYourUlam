# Design System

- **Palette**: Warm paper `#F7F1E5`, card `#FFFBF3`, ink `#2A2118`, clay `#A3431B`, moss `#48582D`, turmeric `#D49A2A`, tamarind `#7B2D3B`, plus full `[data-theme='dark']` pair verified via `npm run contrast`.
- **Typography**: `Young Serif` display headings, `Hanken Grotesk Variable` body, `DM Mono` tabular numbers.
- **Geometry**: Bento grid tiles (`28px` radius, `84px` leaf accent corners) styled exclusively via CSS Modules.
